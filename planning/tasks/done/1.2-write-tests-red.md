## Test Creation Process

### For Each Test File:

1. **Read RED_SPECIFICATION.md** for detailed requirements
2. **Create test class** with proper annotations:
   ```java
   @ExtendWith(MockitoExtension.class)
   public class YourTest {
       @Test
       void testName() { ... }
   }
   ```
3. **Write test methods** following test names above
4. **Use mocks** for UIApplicationService
5. **Keep tests focused** - one behavior per test
6. **Use descriptive assertions** with messages

### Mock Objects Needed

```java
@Mock
private UIApplicationService mockService;

@Mock
private ProjectSelectionListener mockListener;
```

### Location

All test files go in:
```
src/test/java/com/noprobit/tools/ui/
```
