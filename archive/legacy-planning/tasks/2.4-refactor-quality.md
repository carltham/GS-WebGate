## EDT Compliance

### SwingUtilities Usage

Verify:
```java
// CORRECT - EDT update
SwingUtilities.invokeLater(() -> {
    progressBar.setValue(progress);
});

// WRONG - called from worker thread
progressBar.setValue(progress); // NO!
```

### Event Publishing

Use SwingWorker.publish():
```java
protected AnalysisReport doInBackground() {
    // ...
    publish(progressEvent); // Safe - queued for EDT
}

protected void process(List<AnalysisProgressEvent> chunks) {
    // Called on EDT
    updateUI(chunks);
}
```

## Progress Event Validation

### Check Event Content

```java
private void validateProgressEvent(AnalysisProgressEvent event) {
    assertTrue(event.getProgressPercentage() >= 0);
    assertTrue(event.getProgressPercentage() <= 100);
    assertNotNull(event.getCurrentFileName());
    assertTrue(event.getFilesProcessed() <= event.getTotalFiles());
}
```

### Prevent Event Spam

```java
// Throttle progress updates
if (System.currentTimeMillis() - lastUpdateTime > 100) {
    publish(event);
    lastUpdateTime = System.currentTimeMillis();
}
```
