## Writing Tests

### Test Structure Pattern

```java
@ExtendWith(MockitoExtension.class)
public class YourTest {
    
    @Test
    void testName() {
        // Arrange
        
        // Act
        
        // Assert
        assertTrue(...);
    }
}
```

### Reference Documents

- Use `SWING_UI_PHASE0_RED_SPECIFICATION.md` for specific test requirements
- Each test method should test ONE behavior
- Keep test names descriptive (what you're testing, not the method name)
- Use descriptive assertions with messages
