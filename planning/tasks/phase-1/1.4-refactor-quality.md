## Refactoring Focus Areas

### 1. Controller Business Logic Review

**Check:**
- [ ] No UI code in controller
- [ ] No direct panel access
- [ ] No Swing components in controller
- [ ] Only business logic: selection, validation, event firing

**Pattern (correct):**
```java
public class ProjectSelectionController {
    public void selectProject(ProjectMetadata project) {
        // validate, update state, fire event
    }
}
```

**Anti-pattern (incorrect):**
```java
public class ProjectSelectionController {
    private JComboBox dropdown; // NO! This is UI
    public void refreshUI() { dropdown.repaint(); } // NO!
}
```

### 2. Panel MVC Separation Review

**Check:**
- [ ] Panel only displays data
- [ ] Panel delegates logic to controller
- [ ] No business logic in panel
- [ ] All events routed through controller

**Pattern (correct):**
```java
public class ProjectSelectionPanel extends JPanel {
    private ProjectSelectionController controller;
    
    private void onDropdownChange() {
        controller.selectProject(getSelected());
    }
}
```

### 3. Add Logging

**Add logging for:**
- [ ] Project selection
- [ ] Project refresh
- [ ] Error conditions

**Pattern:**
```java
private static final Logger logger = LoggerFactory.getLogger(ProjectSelectionController.class);

public void selectProject(ProjectMetadata project) {
    logger.info("Selecting project: {}", project.getName());
    try {
        // do work
        logger.debug("Project selected successfully");
    } catch (Exception e) {
        logger.error("Failed to select project: {}", project.getName(), e);
    }
}
```

### 4. Optimize Event Firing

**Check:**
- [ ] Events fired at right times
- [ ] No duplicate events
- [ ] Event listeners properly registered
- [ ] No memory leaks from listeners

**Pattern:**
```java
private List<ProjectSelectionListener> listeners = new ArrayList<>();

public void addListener(ProjectSelectionListener listener) {
    listeners.add(listener);
}

private void fireProjectSelected(ProjectMetadata project) {
    ProjectSelectionEvent event = new ProjectSelectionEvent(this, project);
    for (ProjectSelectionListener listener : listeners) {
        listener.projectSelected(event);
    }
}
```

## Review Questions

For each class, answer:

1. **Single Responsibility?**
   - Does this class do one thing?
   - Would a new dev understand its purpose?

2. **Dependencies Clear?**
   - What does it depend on?
   - Are dependencies necessary?
   - Can they be mocked?

3. **Testability?**
   - Is it easy to test?
   - Can we inject dependencies?
   - Can we verify behavior?

4. **Layer Appropriate?**
   - Is controller logic-heavy? (good)
   - Is panel UI-focused? (good)
   - No mixing? (good)
