## Key Concepts

### JTable Model

```java
class ViolationTableModel extends AbstractTableModel {
    public int getRowCount()
    public int getColumnCount()
    public Object getValueAt(int row, int col)
}
```

### Filtering

Pattern:
- Keep original data
- Filter to display subset
- Re-filter on criteria change

### Sorting

Use JTable RowSorter:
```java
TableRowSorter<ViolationTableModel> sorter = new TableRowSorter<>(model);
table.setRowSorter(sorter);
```

### Export Formats

CSV: `class,method,violation,severity`
Markdown: Table format with headers
