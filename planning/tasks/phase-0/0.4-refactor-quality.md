## Refactoring Tasks

### 1. Code Clarity & Naming

**Review each class:**
- [ ] Variable names are descriptive
- [ ] Method names describe what they do
- [ ] Comments explain WHY (not WHAT)
- [ ] Class responsibilities are clear
- [ ] No misleading names

**Examples:**
- ✅ `projectDropdown` instead of `dropdown`
- ✅ `loadConfiguration()` instead of `load()`
- ✅ `initializeUI()` instead of `init()`

### 2. Remove Duplicates

**Check for:**
- [ ] Repeated code patterns
- [ ] Common setup logic
- [ ] Similar error handling

**Actions:**
- Extract to helper methods
- Use inheritance if appropriate
- Use composition

### 3. Add Logging

**Add logging at key points:**
- Application startup
- Window creation
- Project list loading
- Configuration display

**Pattern:**
```java
private static final Logger logger = LoggerFactory.getLogger(ClassName.class);

public void importantMethod() {
    logger.info("Starting important operation");
    try {
        // do work
        logger.debug("Operation details: {}", value);
    } catch (Exception e) {
        logger.error("Failed to do work", e);
    }
    logger.info("Completed operation");
}
```

**SLF4J over System.out:**
- Use SLF4J (Simple Logging Facade)
- Never use `System.out.println()` in production code
- Configure logging in `logback.xml` or `log4j2.xml`

### 4. Verify Layer Separation
