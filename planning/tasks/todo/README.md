# TODO Tasks

Move task files here that are ready to work on but not yet started.

## How to Use

1. When ready to work on a task, move its file from `phase-X/` to `../todo/`
2. As you complete the task, move it to `../done/`
3. This provides visual progress tracking

## Example

```bash
# Start work on phase-0 planning
mv ../phase-0/0.1-planning-setup.md .

# Completed planning
mv 0.1-planning-setup.md ../done/
```
